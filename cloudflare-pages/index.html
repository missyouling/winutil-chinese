📖 什么是 WinUtil？

WinUtil（Windows Utility）是由 Chris Titus Tech 开发的 开源 Windows 系统管理工具箱。本项目在原始基础上进行了 完整中文化， 包含界面、菜单、日志、预设方案在内的全部内容。

✨ 核心功能

• 应用安装 — 一键批量安装常用软件（Winget / Chocolatey）
• 系统优化 — 数十项系统级优化开关，一键应用预设方案
• 功能配置 — 灵活配置 Windows 隐藏功能与隐私选项
• AppX 管理 — 批量卸载预装应用，清理系统臃肿
• Windows 更新控制 — 精细管理更新策略与行为
• Win11 创建工具 — 一键生成纯净的、绕过 TPM/CPU 检查的 ISO
