📌 快速入门

从零开始使用 WinUtil 中文版

🚀 启动 WinUtil

以管理员身份打开 Windows PowerShell，粘贴以下命令并回车：
irm https://win.mozuiapp.com/win | iex
展开详情 ▾
说明：
• irm（Invoke-RestMethod）从指定 URL 下载 PowerShell 脚本内容。
• | iex（Invoke-Expression）将下载的内容直接执行。
• 首次运行会显示 CTT 字符图案，随后自动弹出图形界面。
• 脚本会自动安装所需的 WPF 组件，无需额外配置。
• 如果界面未弹出，尝试在 PowerShell 5.1 中运行，不要使用 PowerShell 7。

🖥️ 界面概览

WinUtil 采用标签式界面，顶部导航栏包含 5 个主要标签页
展开详情 ▾
标签页说明：
• 📦 应用安装 — 浏览分类，选择软件，批量安装/卸载
• ⚡ 系统优化 — 数十项系统优化开关，可分项应用或使用预设方案
• ⚙️ 功能配置 — 配置 Windows 隐藏功能、隐私选项和注册表调整

📦 应用安装

一键批量安装 200+ 款常用软件，支持 Winget 和 Chocolatey 两种包管理器

🔍 浏览与筛选应用 基础

左侧分类栏按类别分组（浏览器、开发工具、多媒体、实用工具等），点击分类可筛选显示对应应用列表。顶部搜索框支持按名称或描述快速查找。
展开详情 ▾
操作步骤：
1. 切换到「应用安装」标签页。
2. 在左侧「分类筛选」中点击感兴趣的分类（如「浏览器」）。
3. 右侧列表显示该分类下的所有应用。
4. 使用顶部的「搜索」框可按关键词过滤应用。
5. 点击「展开/折叠所有分类」可一键展开或收起全部类别。

✅ 选择与批量安装 基础

勾选你想要安装的应用，点击「安装选中的应用」即可自动批量下载安装
展开详情 ▾
操作步骤：
1. 勾选一个或多个应用前的复选框（☐）。
2. 右上角「已选应用」区域显示已选数量，点击可查看详情。
3. 点击「✅ 安装选中的应用」开始批量安装。
4. 任务栏会显示安装进度条，日志区域输出安装详情。
5. 安装完成后会有通知。
• 使用「清除选择」可一键取消所有勾选。
• 使用「显示已安装应用」可标记已通过包管理器安装的软件。

🔄 包管理器切换 进阶

WinUtil 支持 Winget 和 Chocolatey 两种包管理器，可在右上角设置区切换
展开详情 ▾
Winget（默认）—— Windows 原生命令行安装程序，无需额外安装。由 Microsoft 维护，更新及时。
Chocolatey —— 第三方包管理器，拥有更大的软件库。首次使用会自动安装。
切换方式：点击右上角「⚙️设置」按钮，在包管理器选项中选择 Winget 或 Chocolatey。

⚡ 系统优化

🛡️ 隐私与遥测 推荐

关闭 Windows 遥测、广告 ID、位置跟踪、诊断数据收集等隐私相关设置
展开详情 ▾
包含的优化项：
• 禁用遥测 — 阻止 Microsoft 收集诊断和使用数据。对应注册表: HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection\AllowTelemetry=0
• 禁用广告 ID — 关闭用于个性化广告的匿名标识符。
• 禁用位置跟踪 — 阻止应用访问位置信息。
• 禁用诊断数据 — 限制系统发送的诊断信息量。
• 禁用活动历史 — 关闭时间线和活动记录收集。
• 禁用 Cortana — 完全禁用 Cortana 语音助手功能。
注意：部分隐私优化可能在系统更新后恢复，需要重新应用。

🚀 性能优化 推荐

通过禁用动画特效、后台应用、启动项等方式提升系统运行速度
展开详情 ▾
包含的优化项：
• 禁用动画特效 — 关闭窗口淡入淡出、菜单动画等视觉特效，加快界面响应。
• 禁用后台应用 — 阻止 UWP 应用在后台运行以节省资源。
• 禁用透明效果 — 关闭「开始」菜单、任务栏和操作中心的透明效果，降低 GPU 开销。
• 禁用阴影效果 — 关闭窗口阴影，释放少量图形资源。
• 禁用 Xbox Game Bar — 关闭游戏录制叠加层，节省系统资源。
• 禁用鼠标加速 — 关闭「提高指针精确度」选项，适合游戏玩家。
• 禁用启动影响 — 恢复系统启动项的性能影响跟踪。

🎯 体验优化 推荐

关闭开始菜单广告、锁屏兴趣、Bing 搜索等影响使用体验的功能
展开详情 ▾
包含的优化项：

• 禁用 OneDrive — 卸载或禁用 OneDrive 云同步服务。
• 禁用资源管理器广告 — 隐藏文件资源管理器中的 OneDrive/Office 横幅广告。
• 禁用新的 Outlook — 阻止 Windows 推送新版 Outlook 应用。

配置用户账户控制(UAC)、Windows Defender、防火墙等安全相关的设置

🗑️ 卸载预装应用 推荐

选择不需要的预装应用进行批量卸载，可节省大量磁盘空间
展开详情 ▾
建议卸载的常见应用：
• Xbox 系列 — Xbox Game Bar、Xbox Console Companion 等（非 Xbox 玩家）。
• Skype — 已整合到 Teams，如不使用可移除。
• Cortana — 中文地区基本不可用，可安全移除。
• OneNote for Windows 10 — 如使用 Office 365 版 OneNote 可移除。
• 3D Builder — 非 3D 打印用户可移除。
• People — 人脉应用，移动设备上较实用。
• Mixed Reality — 混合现实门户，无 VR 设备可移除。
• News/Finance/Sports — 资讯类应用，可从 Microsoft Store 重新安装。
注意：某些应用（如 Microsoft Store、计算器、照片）不建议卸载，可能影响系统功能。

🔄 重新安装应用 进阶

通过 Microsoft Store 重新安装已卸载的预装应用
展开详情 ▾
如果卸载后需要恢复某个应用，可以通过以下方式：
1. 打开 Microsoft Store 搜索该应用重新安装。
2. 或者在 PowerShell 中运行：Get-AppxPackage -AllUsers *PackageName* | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml"}
WinUtil 本身不提供 AppX 恢复功能，建议卸载前记录应用完整名称。

🔄 Windows 更新控制

精细管理 Windows Update 的行为，在安全与可控之间找到平衡

⏸️ 暂停更新 推荐

临时暂停 Windows 更新，避免在关键时刻被重启打断
展开详情 ▾
操作方式：
1. 进入「Windows 更新」标签页。
2. 在「暂停更新」区域选择暂停时长（例如 7 天、30 天）。
3. 系统会将更新推迟到指定期限后才继续检查更新。
• 适合：正在进行重要工作、演示或不希望重启时。
• 注意：暂停期结束后，Windows 仍会自动更新。长期禁用更新可能带来安全风险。

🚫 禁用 Windows 更新 谨慎

通过禁用更新服务和计划任务，完全阻断 Windows 更新
展开详情 ▾
影响：
• 停止并禁用 Windows Update 服务 (wuauserv)。
• 停止并禁用 BITS 后台智能传输服务。
• 停止并禁用更新 Orchestrator 服务 (UsoSvc)。
• 禁用所有与更新相关的计划任务。
• 清除 SoftwareDistribution 文件夹。
⚠️ 风险提示：完全禁用更新将使系统无法接收安全补丁。建议仅在以下情况使用：
• 配置较低的旧设备，更新后可能出现卡顿。
• 企业环境中由 IT 部门统一管理更新。
• 临时禁用以便进行长时间的不间断操作。
可通过「启用更新」按钮恢复默认更新行为。

🔄 更新策略配置 进阶

通过组策略注册表项精确控制 Windows 更新的行为
展开详情 ▾
包含的策略配置：
• 延迟功能更新 — 推迟功能更新（每年大版本）最多 365 天。
• 延迟质量更新 — 推迟安全/质量更新（每月补丁）最多 30 天。
• P2P 更新分发 — 关闭 Windows 更新对等分发（减少上传流量）。
• 驱动更新 — 禁止 Windows 更新自动更新驱动程序。
• 重启调度 — 配置更新的自动重启时间和通知策略。
• 活跃时间 — 设置在活跃时间内不重启。

💿 Win11 创建工具

一键创建绕过 TPM 2.0、CPU、内存检查的 Windows 11 安装镜像

📥 下载并创建 ISO 基础

直接从 Microsoft 服务器下载最新 Windows 11 镜像，自动应用绕过检查补丁
展开详情 ▾
操作步骤：
1. 进入「Win11ISO」标签页。
2. 点击「下载 Windows 11」按钮。
3. 脚本自动从官网下载并构建安装 ISO。
4. ISO 会在生成时包含绕过 TPM 2.0、CPU 系列/型号、4GB 内存、Secure Boot 等检查的配置文件。
5. 下载完成后，ISO 文件会保存在指定位置（默认桌面）。
• 整个过程需要良好的网络连接。
• ISO 包含 Windows 11 专业版/家庭版等多版本选择。

🔧 绕过检查说明 进阶

WinUtil 自动注入的绕过补丁及其原理
展开详情 ▾
WinUtil 会绕过以下硬件检查：
• TPM 2.0 — 跳过受信任平台模块 2.0 检测（注册表: BypassTPMCheck）。
• CPU — 跳过处理器系列/型号检查（注册表: BypassCPUCheck）。
• RAM — 跳过 4GB 内存下限检查（注册表: BypassRAMCheck）。
• Secure Boot — 跳过安全启动检查（注册表: BypassSecureBootCheck）。
• Storage — 跳过 64GB 存储空间检查（注册表: BypassStorageCheck）。
• 磁盘类型 — 允许在 IDE/SCSI 硬盘上升级。
• TpmCheck — 绕过 TPM 检查（注册表: BypassTpmCheck）。
注意：绕过硬件检查后，Windows 11 在不受支持的硬件上可能遇到稳定性、驱动或更新问题。

💡 使用技巧 提示

如何有效使用预设方案
展开详情 ▾

• 你可以在方案基础上额外勾选或取消勾选任意优化项。

❓ 常见问题

使用 WinUtil 过程中常见的问题与解答

❓ 运行后没有任何反应 / 界面不弹出

可能的原因和解决方案
展开详情 ▾
• 确保以 管理员身份 运行 PowerShell。
• 确保使用的是 PowerShell 5.1（而非 PowerShell 7），WinUtil 基于 WPF 构建。
• 检查是否被 Windows Defender / 杀毒软件拦截了脚本执行。
• 尝试在命令行后添加 -NoExit 参数查看错误信息：powershell -NoExit -Command \"irm https://win.mozuiapp.com/win | iex\"
• 如果输出包含中文乱码，说明编码有问题，建议使用最新的 Windows 10/11 版本。

❓ 提示「拒绝访问」错误

权限不足导致某些操作无法执行
展开详情 ▾
• 部分优化项（如禁用 Windows Update 服务）需要 TrustedInstaller 权限。
• 以管理员身份运行即可解决大部分权限问题。
• 某些系统级操作（如修改 HKLM 注册表）需要管理员权限。
• 如果仍遇到拒绝访问，请在干净的 Windows 系统上执行（非企业域环境）。

❓ 如何撤销优化？

恢复系统到优化前的状态
展开详情 ▾
• WinUtil 的多数优化开关支持撤销（Undo）。
• 取消勾选该优化项，点击「运行选中的优化」即可执行撤销。
• 部分优化（如注册表调整）会自动备份原始值。
• 如果遇到无法撤销的情况，可通过系统还原点恢复。
• 建议在重大优化前创建系统还原点。

❓ 应用安装功能不工作

Winget 或 Chocolatey 安装失败
展开详情 ▾
• 确保系统已安装 Winget（Windows 10 1809+ / Windows 11 自带）。
• 如果使用 Chocolatey，首次运行会自动安装，需要管理员权限。
• 检查网络连接，部分安装源可能需要科学上网。
• 某些企业环境组策略可能禁止安装软件，需联系 IT 部门。
• 尝试切换包管理器（Winget ↔ Chocolatey）看能否解决问题。

❓ 显示乱码 / 中文不完整

界面文字显示异常
展开详情 ▾
